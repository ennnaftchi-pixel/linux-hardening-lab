# Linux Hardening Lab

Personal lab environment to explore Linux system security and hardening techniques.

## 🔐 Focus Areas

* SELinux configuration
* Firewall auditing (iptables / firewalld)
* User privilege management
* System attack surface reduction

## 🧪 Environment

* Host: Fedora / Arch (dual boot)
* Virtualization: KVM / QEMU
* Network isolation for testing

## 🎯 Goal

To understand how Linux systems can be secured from a **defensive and adversarial perspective**.
